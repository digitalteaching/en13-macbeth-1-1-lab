# Macbeth 1.1 · The Witches’ Lab

Reading & Writing Lab Englisch EN13 zur ersten Szene von *Macbeth* (die drei Hexen), gemeinsam getaktet in sieben Phasen: Thunder, Read, The Original (First Folio 1623), Sound, Close Reading, Echo, Write. Mit Freigabe-Codes, Lehrkraft-Modus und QR-Abgabe der Schreibaufgabe. Eine HTML-Datei, passwortgeschützt (Inhalt verschlüsselt; Lehrerteil mit eigenem Passwort).

Text: Folger Shakespeare (Folger Digital Texts, CC BY-NC 3.0). First Folio: Bodleian Library, Arch. G c.7 (CC BY 3.0).
