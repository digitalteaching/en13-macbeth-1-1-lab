# Macbeth, Act 1 · The Witches’ Lab

Reading & Writing Lab Englisch EN13 zu *Macbeth* 1.1–1.3 (die Hexen, die Schlacht, die Prophezeiung, Macbeths Aside), gemeinsam getaktet in neun Phasen über zwei Doppelstunden. Mit Freigabe-Codes, Motiv-Log, Sicherung, Lehrkraft-Modus und QR-Abgabe der Schreibaufgabe. Dazu eine Lehrerfassung mit Hinweisen (Aussprache, Figuren, Hintergrund, mögliche Fragen) unter /lehrer/.

Beide Seiten sind passwortgeschützt (Inhalt verschlüsselt).

Text: Folger Shakespeare (Folger Digital Texts, CC BY-NC 3.0). First Folio: Bodleian Library, Arch. G c.7 (CC BY 3.0).
